Cite the method and repository

If you use this repository or its LFMC estimates in a publication, please cite:

Pampanoni, V.; Chuvieco, E.; Ferrari, A.; Laneve, G.; Saquella, S. (2026). A Unified Multisensor Machine-Learning Framework for Live Fuel Moisture Content Retrieval. Remote Sensing, 18(21), 3744. https://doi.org/10.3390/rs18213744.

Download the BibTeX reference. The repository's CITATION.cff also identifies this article as the preferred citation, enabling GitHub's citation interface to refer to the paper.

Record the software version or commit used and retain each output's provenance JSON. The article DOI identifies the scientific paper; no separate software DOI has been assigned to this development candidate.

Paper illustration

The Camp Fire comparison comes from Figure A3 of the article. It is reproduced without modification, with attribution to Pampanoni and coauthors (2026), under the Creative Commons Attribution 4.0 International licence.

The first-map tutorial reuses the Sentinel-2 acquisition date from Figure A3 over a smaller area. It uses the release workflow's fixed WorldCover 2021 snapshot and original AgERA5 weather. The figure uses pre-fire Dynamic World vegetation routing and terrain-adjusted weather.
